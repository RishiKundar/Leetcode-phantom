## ⚡ What is this?

**LeetCode Phantom** is a personal DSA practice repository containing solved LeetCode problems in **Java**. Each problem lives in its own folder, with the solution code alongside the original problem statement.

The goal is simple:

> **Solve. Understand. Repeat. Improve.**

The repository is intentionally organized as a searchable trail of problems and patterns rather than a giant collection of unrelated snippets.

## 👻 The Phantom Workflow

<img src="https://raw.githubusercontent.com/andreasbm/readme/master/assets/lines/rainbow.png" width="100%" alt="Rainbow divider" />

```text
          ┌─────────────────┐
          │   🧠 Understand  │
          └────────┬────────┘
                   ↓
          ┌─────────────────┐
          │   ✍️  Implement  │
          └────────┬────────┘
                   ↓
          ┌─────────────────┐
          │   🧪 Test / Fix  │
          └────────┬────────┘
                   ↓
          ┌─────────────────┐
          │   ✅ Accepted    │
          └────────┬────────┘
                   ↓
          ┌─────────────────┐
          │   👻 Next Problem│
          └─────────────────┘
```

The emphasis is not just on collecting accepted submissions. The real objective is to recognize **patterns**, understand why a solution works, and become faster at approaching unfamiliar problems.

**The work disappears. The skill stays. 👻**
